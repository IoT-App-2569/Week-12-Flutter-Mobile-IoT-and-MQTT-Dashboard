## 4. สรุปผลและคำถามท้ายการทดลอง
1. เหตุใดการใช้ `TweenAnimationBuilder` จึงทำให้เข็มมาตรวัดดูนุ่มนวลและไม่กระตุก แม้ข้อมูลเซนเซอร์จะเข้ามาทุกๆ 500 มิลลิวินาที?

   **ตอบ** เพราะ TweenAnimationBuilder ช่วยคำนวณและสอดแทรกค่าระหว่างจุดเดิมไปยังจุดใหม่ (Interpolation) โดยใช้เส้นโค้งความเร่ง Curves.easeOutCubic ภายในเวลา 300 ms ทำให้เข็มกวาดต่อเนื่องอย่างราบรื่น แทนที่จะกระโดดข้ามตำแหน่งทันทีเมื่อมีข้อมูลใหม่เข้ามา

2. การจำกัดความยาวของอาร์เรย์ `_history` ให้เก็บไม่เกิน 30 ตัวอย่าง ส่งผลดีต่อประสิทธิภาพหน่วยความจำของสมาร์ตโฟนอย่างไร?

   **ตอบ** ป้องกันปัญหาหน่วยความจำรั่วไหล (Memory Leak) และช่วยควบคุมภาระการวาดของ CustomPainter ให้คงที่คงระดับ $O(1)$ ทำให้การเรนเดอร์กราฟไม่หน่วงหรือกระตุกเมื่อเปิดแอปพลิเคชันทิ้งไว้เป็นเวลานาน
   
3. หากเซนเซอร์ส่งค่าผิดพลาด เช่น ค่านอกช่วง 0 - 3.3V หรือค่าเป็น `null` โค้ดส่วนใดใน `telemetry_dashboard_screen.dart` ที่ช่วยป้องกันไม่ให้แอปแครช?

   **ตอบ**
   - Safe Type Casting & Fallback: โค้ด (data['voltage'] as num?)?.toDouble() ?? 0.0 ช่วยป้องกัน Null Pointer และข้อผิดพลาดทางชนิดข้อมูล โดยคืนค่าเริ่มต้นเป็น 0.0 ทันที
   - ฟังก์ชัน .clamp(0.0, 1.0): บังคับสัดส่วนค่าที่นำไปวาดไม่ให้หลุดออกนอกขอบเขตพื้นที่หน้าปัดและกราฟ
   - บล็อก try-catch: ครอบคำสั่ง jsonDecode เพื่อดักจับกรณีโครงสร้าง JSON ผิดรูปแบบหรือไม่สมบูรณ์
