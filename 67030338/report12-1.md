### ข้อ 1: เพราะเหตุใดเราจึงต้องสุ่มชื่อ `clientId` เช่นการใส่ Timestamp ต่อท้าย แทนที่จะตั้งชื่อแบบคงที่?
* **คำตอบ:**
  * **มาตรฐานของโปรโตคอล MQTT:** กำหนดไว้ว่า `clientId` จะต้องมีความไม่ซ้ำกัน (**Unique**) ต่อหนึ่งโฮสต์/เซสชันบน Broker เดียวกัน
  * **ประโยชน์ของการใส่ Timestamp:** การนำเวลาปัจจุบันในระดับมิลลิวินาที (เช่น `DateTime.now().millisecondsSinceEpoch`) หรือสุ่ม UUID มาต่อท้าย จะรับประกันว่า `clientId` จะไม่ซ้ำกันอย่างแน่นอนในแต่ละเซสชัน ทำให้การเชื่อมต่อเสถียรและไม่ตัดกันเอง

### ข้อ 2: หากหน้าจอ Flutter รันบนอุปกรณ์จริง (Physical Android Phone) เหตุใดการกรอก IP `127.0.0.1` จึงไม่สามารถเชื่อมต่อ Broker ได้? และต้องใช้ IP ใด?
* **คำตอบ:**
  * **เหตุผลที่ `127.0.0.1` เชื่อมต่อไม่ได้:**
    * `127.0.0.1` คือหมายเลข **Loopback Address (Localhost)** ซึ่งหมายถึง "ตัวเครื่องที่โปรแกรมกำลังทำงานอยู่เท่านั้น"
    * เมื่อแอปพลิเคชันทำงานอยู่บนสมาร์ตโฟนจริง การระบุ `127.0.0.1` จะหมายถึงตัวเครื่องสมาร์ตโฟนเอง ซึ่งบนมือถือไม่ได้ติดตั้งหรือรัน Mosquitto Broker ไว้ จึงส่งผลให้เกิดข้อผิดพลาด `SocketException: Connection refused (errno = 111)`
  * **หมายเลข IP ที่ต้องใช้:**
     **กรณีเชื่อมต่อไร้สายผ่าน Wi-Fi:** ต้องระบุ **หมายเลข IPv4 Address ของเครื่องคอมพิวเตอร์** ที่รัน Broker อยู่ในเครือข่ายแลนเดียวกัน (เช่น `10.15.5.186` หรือ `192.168.x.x` )
