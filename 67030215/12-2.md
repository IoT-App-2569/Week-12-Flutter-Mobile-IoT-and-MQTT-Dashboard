#### 1. จำลองส่งสถานะ Online (เสมือน ESP32 บูตเสร็จ)
```powershell
mosquitto_pub -h 127.0.0.1 -p 1883 -t "iot/esp32/status" -m "online" -r
```
*สังเกตหน้าจอ Flutter แถบสถานะด้านบนจะเปลี่ยนเป็นสีเขียวทันที*

<img width="386" height="587" alt="image" src="https://github.com/user-attachments/assets/e2ce1a68-bc29-4dde-a14a-0e55757403c3" />


#### 2. เฝ้าดูคำสั่งที่ส่งมาจากแอป Flutter
```powershell
mosquitto_sub -h 127.0.0.1 -p 1883 -t "iot/esp32/control" -v
```
<img width="267" height="597" alt="image" src="https://github.com/user-attachments/assets/8d2f34e4-9901-4005-82f2-7dfb78007fc9" />

*เมื่อแตะสวิตช์บน Flutter จะเห็นแพ็กเก็ต `{"led":"ON"}` หรือ `{"led":"OFF"}` ปรากฏในเทอร์มินัล*
<img width="937" height="63" alt="image" src="https://github.com/user-attachments/assets/1f961332-ed72-4009-b09a-945818e266bf" />

#### 3. ส่งคำสั่งยืนยันกลับไปยังแอป (เสมือนบอร์ดเปลี่ยนสถานะขา GPIO สำเร็จ)
```powershell
mosquitto_pub -h 127.0.0.1 -p 1883 -t "iot/esp32/led_ack" -m '{"led_state": true, "ack": true}'
```

<img width="387" height="693" alt="image" src="https://github.com/user-attachments/assets/fcd87da4-0d71-4f3a-b5fd-97b6bf3b208c" />

*สังเกตสวิตช์และไอคอนหลอดไฟบนมือถือจะเรืองแสงสีเขียวทันที*

#### 4. จำลองเหตุการณ์บอร์ดดับหรือเน็ตหลุด (เสมือน Broker ส่ง LWT)
```powershell
mosquitto_pub -h 127.0.0.1 -p 1883 -t "iot/esp32/status" -m "offline" -r
```
*สังเกตว่าหน้าจอจะแจ้งเตือนว่า ESP32 ออฟไลน์ทันที และสวิตช์จะไม่ยอมให้สั่งการ*

## 4. สรุปผลและคำถามท้ายการทดลอง

1. **ประโยชน์ของการรอสัญญาณ ACK จากหัวข้อ `iot/esp32/led_ack` แทนการเปลี่ยน UI ทันที (Optimistic Update) คืออะไร?**
```
เพื่อยืนยันสถานะการทำงานจริงทางกายภาพของฮาร์ดแวร์ (Physical State Synchronization) ป้องกันปัญหา UI แสดงผลผิดพลาดกรณีสัญญาณเครือข่ายหลุด คำสั่งส่งไม่ถึงบอร์ด 
หรือฮาร์ดแวร์เกิดข้อผิดพลาด ซึ่งหากใช้ Optimistic Update แอปจะแสดงว่าเปิดไฟสำเร็จแล้ว ทั้งที่ความเป็นจริงฮาร์ดแวร์ยังไม่ได้ทำงาน
```
2. ทำไมเราจึงควรตั้งแฟล็ก Retain (`-r`) สำหรับหัวข้อสถานะ `iot/esp32/status`?
```
เพื่อให้ Broker บันทึกข้อความสถานะล่าสุด (online/offline) ค้างไว้ในระบบ เมื่อมีแอป Flutter เปิดขึ้นมาใช้งานใหม่ 
หรือเชื่อมต่อเข้า Broker ทีหลัง จะสามารถอ่านและรับรู้สถานะปัจจุบันของอุปกรณ์ ESP32 ได้ทันที โดยไม่ต้องรอให้อุปกรณ์ส่งสัญญาณรอบใหม่
```
