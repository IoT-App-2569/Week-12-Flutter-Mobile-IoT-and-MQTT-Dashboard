### 2. คำถามท้ายบทเรียน (Review Questions)

**1. เหตุใดการใช้ `IndexedStack` ใน `MainNavigationShell` จึงมีความสำคัญอย่างยิ่งสำหรับแอปพลิเคชัน IoT แบบ Multi-tab เมื่อเทียบกับการสลับวิดเจ็ตด้วย `body: _pages[_currentIndex]`?**

**ตอบ:** 

* `IndexedStack` ช่วยรักษาสถานะ ของหน้าจอทั้งหมดไว้ในหน่วยความจำแม้จะสลับแท็บไปมา 
* หากใช้ `_pages[_currentIndex]` หน้าจอจะถูกทำลายและสร้างใหม่ทุกครั้ง ทำให้การเชื่อมต่อ MQTT ถูกตัดและต้องทำการเชื่อมต่อใหม่ตลอดเวลา ซึ่งไม่เหมาะสมกับระบบ IoT ที่ต้องการการเชื่อมต่อแบบเรียลไทม์อย่างต่อเนื่อง

**2. เมื่อเปรียบเทียบการพัฒนาด้วย Flutter ในสัปดาห์นี้ กับการเปิดหน้าเว็บ HTTP บนเบราว์เซอร์ในสัปดาห์ที่ 8-10 ข้อใดให้ประสบการณ์การใช้งาน (UX) และความเสถียรที่ดีกว่าเมื่อข้อมูลเซนเซอร์มาด้วยความถี่สูง? เพราะเหตุใด?**

**ตอบ:** 

* การพัฒนาด้วย Flutter ร่วมกับโปรโตคอล MQTT ให้ประสบการณ์การใช้งานและความเสถียรที่ดีกว่ามาก 
* เนื่องจาก MQTT ใช้การเชื่อมต่อผ่าน TCP Socket แบบเปิดค้างไว้ ทำให้สามารถรับส่งข้อมูลความถี่สูงได้ทันทีโดยมี Overhead ต่ำมาก 
* ในขณะที่ HTTP แบบดั้งเดิมต้องสร้างการเชื่อมต่อใหม่ทุกครั้งที่ร้องขอข้อมูล ทำให้เกิดความหน่วงสูง และเบราว์เซอร์มักจะทำงานหนักหรือค้างเมื่อต้องรีเฟรชส่วนประกอบบนหน้าจอ อย่างต่อเนื่อง

**3. หากต้องการนำแอปพลิเคชันนี้ไปเผยแพร่จริงบน Google Play Store หรือ Apple App Store ขั้นตอนความปลอดภัยที่ต้องปรับปรุงเพิ่มเติมมีอะไรบ้าง?**

**ตอบ:** 

* ต้องเปลี่ยนการเชื่อมต่อจากพอร์ต 1883 แบบไม่เข้ารหัส ไปใช้พอร์ต 8883 ที่รองรับโปรโตคอล MQTTS / TLS เพื่อเข้ารหัสข้อมูลระหว่างการส่ง 
* ต้องเพิ่มการยืนยันตัวตน เช่น การใช้ Username/Password หรือ Authentication Token ในการอนุญาตเข้าถึง Broker 
* ข้อมูลรับรอง เหล่านี้จะต้องถูกจัดเก็บอย่างปลอดภัยใน Secure Storage ของสมาร์ตโฟน
